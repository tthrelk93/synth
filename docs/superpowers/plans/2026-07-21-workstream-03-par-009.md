**Goal:** Finish Workstream 03 by replacing render-time string parameter lookups with one coherent typed 48-parameter snapshot and replacing the editor's duplicated ID/normalization/polling maps with prepared typed bindings.

The editor owns prepared attachment-style bindings keyed by the same enum; parameter-to-component updates are listener-driven, while Signal Flow visualization reads a coherent processor snapshot.

- [x] **Step 5: Implement bounded sanitizing capture**

  Capture all raw physical atomics between equal acquire-loaded even generations. Sanitize without changing APVTS: non-finite values use the descriptor default and increment an atomic diagnostic; continuous values clamp to descriptor endpoints; choices round and clamp; booleans become exact false/true; priority and trigger clamp to their enum domains. Use exactly three attempts and return the caller's coherent fallback or the constructor-built default snapshot.

  The core loop must have this shape:

  ```cpp
  for (int attempt = 0; attempt < 3; ++attempt) {
      const auto before = stateGeneration.load (std::memory_order_acquire);
      if ((before & 1u) != 0u) continue;
      std::array<float, ParameterRegistry::parameterCount> values {};
      for (std::size_t i = 0; i < values.size(); ++i)
          values[i] = preparedParameterHandles[i]->load (std::memory_order_relaxed);
      const auto contract = contourContractCache.load (std::memory_order_acquire);
      const auto after = stateGeneration.load (std::memory_order_acquire);
      if (before == after && (after & 1u) == 0u)
          return buildTypedSnapshot (values, contract, after);
  }
  ```

  `buildTypedSnapshot` must be `noexcept` and allocation-free.
